\# DevOps Project: CI/CD Pipeline with Monitoring



\## Tools Used

\- Docker

\- Docker Compose

\- Prometheus

\- Grafana

\- Node.js



\## Description

This project demonstrates a containerized Node.js application with integrated monitoring using Prometheus and visualization using Grafana.



\## Features

\- Dockerized application

\- Real-time monitoring using Prometheus

\- Dashboard visualization using Grafana

\- CPU, Memory, and Uptime tracking
